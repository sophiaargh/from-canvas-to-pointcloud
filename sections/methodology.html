III. Methodology

A Stylized Multi-View Benchmark

We develop a benchmark of stylized multi-view images, since 3D reconstruction datasets like BlendedMVS and DTU provide ground-truth geometry but lack artistic variance.

As shown in Figure 1, we generate stylized variants (Impressionism, Oil painting, Engraving, Watercolor) of BlendedMVS while preserving 3D geometry. To do this we use TeleStyle [18], a content-preserving style-transfer model built on Qwen-Image-Edit-2509 [19]. It takes a content and a style reference image as input, producing a stylized output that preserves structure and composition while adopting the target aesthetic. To fit in the time and compute constraints, we stylize each frame in just four diffusion steps via a Lightning distillation for speed, keep only scenes with fewer than 150 views, and stylize every fifth image. We then obtain a benchmark of 80 scenes which contain 15 views on average. All with the ground truth camera positions and depth maps. The dataset can be found in this link.

Mini-Benchmark of Real Artistic Images

Moreover, to assess model performance on our target use case, we collect images of three well-known architectural landmarks: Notre-Dame de Paris, the Rialto Bridge in Venice, and the Doge's Palace. Each is represented across three stylistic modalities: historical photographs, sketches, and paintings sourced from public archives. This selection is motivated by a concrete real-world scenario: recovering the 3D geometry of structures that have been transformed, damaged, or lost over time, for which only heterogeneous artistic documentation remains. This creates a mini benchmark for qualitative evaluation, as ground truth point clouds are not available.

Evaluation

Our baseline is the unmodified MapAnything, the state-of-the-art feed-forward reconstruction model we build on. Photographic inputs act as the in-distribution reference and each artistic style as an out-of-distribution test, so the photograph-versus-style gap directly measures the cost of style shift. Before any architecture adaptation, we evaluate this baseline on our benchmark; to fit into memory we feed at most 8 views per scene, which does not hinder the analysis since our goal is style robustness rather than scene coverage.

We report four metrics. Depth quality is measured by AbsRel (mean absolute relative depth error, |dpred − dgt| / dgt over valid pixels) and RMSE (root-mean-square depth error). Geometry quality is measured by the Chamfer distance (symmetric mean nearest-neighbour distance between the predicted and ground-truth point clouds, in metres) and the F-score (harmonic mean of precision and recall, counting points within a threshold of τ = 2% of the scene scale). Lower is better for AbsRel, RMSE and Chamfer; higher is better for the F-score.

Destylization

A natural candidate for an additional baseline is to first remove the artistic style from each image before passing it to MapAnything—a destylization pre-processing step—so as to recover an approximation of the original photograph. Such a pipeline would test whether the reconstruction gap introduced by stylization (Table 1) can be closed by style removal alone, without any architectural adaptation.

We explored two destylization strategies. The first, Reverse TeleStyle, reuses the TeleStyle pipeline in the reverse direction: the stylized image serves as the content input and the original photograph acts as the photorealistic style reference, instructing the model to transfer the photographic style back onto the content. The second strategy, ControlNet img2img, is motivated by the need to decouple style removal from scene content. A plain img2img diffusion pipeline risks hallucinating scene content, while conditioning on text alone provides no structural anchor. We therefore extract a depth map from the stylized image using a DPT estimator [20] and use it as a geometric condition for a Stable Diffusion 1.5 [21] ControlNet [22] img2img pipeline: the stylized image initializes the diffusion process (preserving scene content) while the depth map constrains the geometry, and a photorealistic prompt — paired with a negative prompt penalising painterly and stylized textures — pushes the style toward realism. The pipeline exposes two free parameters — the img2img denoising strength and the ControlNet conditioning scale — which we sweep jointly in our experiments.

Architecture Modifications

The MapAnything architecture uses the first 24 layers of a DINOv2-L model as its dense image encoder, with the subsequent 16 layers repurposed to initialize the Alternating Attention (AA) blocks. During training, the encoder was fine-tuned end-to-end with a conservative learning rate of 5×10−6 (versus 10−4 for the AA blocks and task heads), enabling it to specialize in depth-centric and view-consistent features.

We restrict all modifications exclusively to the DINOv2 encoder, keeping the downstream AA blocks and prediction heads frozen. Since DINOv2 was trained on natural photographs, stylized inputs induce severe out-of-distribution activations at this entry point; adapting the AA blocks would be counter-productive if the encoder fails to preserve the geometry-related signals required for multi-view matching.

Feature-Space Normalization

Instance Normalization is applied directly to intermediate feature tensors between DINOv2 layers, standardizing activations to 𝒩(0, 1) to strip style-specific texture statistics. This method is entirely training-free and serves as a lightweight baseline.

Adaptive Instance Normalization (AdaIN)

Learnable AdaIN affine layers are inserted between encoder layers and optimized via cross-domain distillation. A frozen teacher model processes photographs while a student (identical model with AdaIN layers) processes matched stylized inputs, supervised by an L1 loss on predicted depth maps (𝔻) and 3D point clouds (ℙ):

ℒ = α ‖ 𝔻student(Xstyle) − 𝔻teacher(Xphoto) ‖1  +  β ‖ ℙstudent(Xstyle) − ℙteacher(Xphoto) ‖1

By minimizing the discrepancy between the student’s predictions on stylized inputs and the teacher’s predictions on photographs, the encoder is encouraged to extract style-invariant geometric cues without altering downstream structural reasoning.

Low-Rank Adapters (LoRA)

Trainable low-rank adapter matrices are injected directly into the attention projections of MapAnything's DINOv2 backbone. Each targeted weight matrix W ∈ Rd×k is augmented with a factored residual update ΔW = BA, where B ∈ Rd×r, A ∈ Rr×k, and r ≪ min(d, k). During the forward pass the layer computes y = Wx + BAx: the frozen base projection and the low-rank correction are summed, so the adapter learns only the residual shift needed to handle stylized inputs. All base weights remain frozen during training; only the adapter parameters are updated.

The model is fine-tuned on BlendedMVS scenes rendered across multiple artistic styles (engraving, impressionism, oil painting, watercolor) using TeleStyle, with each training sample mixing styled and original views to encourage style-invariant predictions. An optional consistency regularization term additionally penalizes discrepancies between the model's 3D point predictions on styled versus original images:

\[\mathcal{L}_{\text{consistency}} = \frac{1}{V}\sum_{i=1}^{V} \left\| P_i^{\text{styled}} - \text{sg}(P_i^{\text{original}}) \right\|_2^2\]

where sg(·) denotes the stop-gradient operator. This allows the adapter to learn style robustness directly from the domain shift observed at training time, while keeping the parameter overhead minimal.
